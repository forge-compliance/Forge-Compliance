FORGE COMPLIANCE ENGINEERING OPERATIONS DEMO v1.0

Purpose
-------
Public-facing interactive demonstration for forgecompliance.co.uk.
Uses fictional demo data only. No Limewood records, no Supabase connection, no live contractors.

Recommended URL
---------------
https://forgecompliance.co.uk/demo/

Deploy
------
Create a /demo/ folder in the Forge Compliance website and upload index.html into it.

What it demonstrates
--------------------
- Engineering control-centre dashboard
- Plant rooms
- Asset register and lifecycle history
- Valve register
- PPM Centre
- Maintenance issue management
- Contractor quotations and approvals
- Compliance / QR logging concept
- Future finance and budget layer
- End-to-end fault -> contractor -> approval -> cost workflow

Before public launch
--------------------
1. Connect the "Request Demo" button/form to the real Forge Compliance enquiry workflow.
2. Add your actual website navigation/header if you want it visually identical to forgecompliance.co.uk.
3. Consider adding a short privacy notice if the enquiry form collects personal information.
4. Keep this demo separate from the live Limewood/Supabase application.
