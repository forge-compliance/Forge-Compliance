# Forge Compliance Website V2

## Upload to GitHub Pages
1. Delete the old repository files, but keep the repository itself.
2. Extract this ZIP on your computer.
3. Upload **the contents inside `forge-compliance-v2`**, not the outer folder.
4. The repository root must show `index.html`, `.nojekyll`, and the `assets` folder.
5. In GitHub go to **Settings → Pages**.
6. Select **Deploy from a branch**, `main`, and `/(root)`.
7. Wait for the Pages deployment to turn green, then use Ctrl+F5.

## Email
The contact form opens the visitor's email application and prepares an email to `hello@forgecompliance.co.uk`. Replace that address throughout the HTML if your final address differs.
